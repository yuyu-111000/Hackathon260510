# API 接口文档

> Base URL: http://localhost:8000

## 1. 健康检查

### GET /health

**响应:**
```json
{
  "status": "ok",
  "version": "1.0.0"
}
```

---

## 2. 教材管理

### POST /api/textbooks/upload

上传教材文件。

**请求:** `multipart/form-data`
- `file`: 文件（PDF/MD/TXT）

**响应:** Textbook 对象
```json
{
  "textbook_id": "book_abc123",
  "filename": "病理学.pdf",
  "title": "病理学",
  "file_type": "pdf",
  "total_pages": 0,
  "total_chars": 0,
  "status": "uploaded",
  "chapters": []
}
```

### GET /api/textbooks

获取所有教材列表。

**响应:** Textbook[]

### GET /api/textbooks/{id}

获取单个教材详情。

**响应:** Textbook 对象

### POST /api/textbooks/{id}/parse

解析教材，提取章节。

**响应:** Textbook 对象（包含 chapters）

---

## 3. 知识图谱

### POST /api/graph/build

从已解析教材构建知识图谱。

**参数:**
- `textbook_id` (可选): 指定教材 ID，不传则构建全部

**响应:** GraphResponse
```json
{
  "nodes": [
    {
      "id": "book_001_ch001_n000",
      "textbook_id": "book_001",
      "name": "细胞膜",
      "aliases": [],
      "definition": "细胞的外层边界，由磷脂双分子层组成",
      "category": "核心概念",
      "chapter": "第一章 细胞生物学",
      "page": 1,
      "source_quote": "细胞膜是细胞的外层边界",
      "frequency": 1,
      "status": "raw"
    }
  ],
  "edges": [
    {
      "source": "book_001_ch001_n000",
      "target": "book_001_ch001_n001",
      "relation_type": "prerequisite",
      "description": "细胞膜是细胞结构的基础",
      "textbook_id": "book_001"
    }
  ]
}
```

### GET /api/graph

获取当前知识图谱。

**响应:** GraphResponse

### GET /api/graph/merged

获取整合后的知识图谱。

**响应:** GraphResponse

---

## 4. 跨教材整合

### POST /api/integration/run

运行跨教材整合分析。

**响应:** IntegrationRunResponse
```json
{
  "decisions": [
    {
      "decision_id": "merge_000",
      "action": "merge",
      "affected_nodes": ["node_1", "node_2"],
      "result_node": "merged_000",
      "reason": "多个教材中的'细胞膜'描述同一概念",
      "confidence": 0.9,
      "status": "active"
    }
  ],
  "stats": {
    "original_total_chars": 50000,
    "compressed_chars": 12000,
    "compression_ratio": 24.0,
    "original_node_count": 200,
    "merged_node_count": 80,
    "merge_count": 40,
    "keep_count": 60,
    "remove_count": 100
  },
  "merged_graph": { ... }
}
```

### GET /api/integration/decisions

获取所有整合决策。

**响应:** MergeDecision[]

### PATCH /api/integration/decisions/{id}

修改决策。

**参数:**
- `action`: "keep" | "remove" | "merge"

**响应:** MergeDecision

## 5. RAG 问答

### POST /api/rag/index

构建 RAG 索引。

**响应:**
```json
{
  "status": "indexed",
  "books": 7,
  "chunks": 1500
}
```

### GET /api/rag/status

获取 RAG 索引状态。

**响应:**
```json
{
  "indexed_books": 7,
  "chunk_count": 1500,
  "status": "ready"
}
```

### POST /api/rag/query

RAG 查询。

**请求:**
```json
{
  "question": "什么是细胞膜？"
}
```

**响应:** RAGQueryResponse
```json
{
  "answer": "细胞膜是细胞的外层边界，由磷脂双分子层组成[病理学, 第一章, 第5页]。",
  "citations": [
    {
      "textbook": "病理学",
      "chapter": "第一章 细胞生物学",
      "page": 5,
      "relevance_score": 0.92,
      "quote": "细胞膜是细胞的外层边界"
    }
  ],
  "source_chunks": ["细胞膜是细胞的外层边界..."]
}
```

## 6. 教师反馈

### POST /api/chat

发送教师反馈消息。

**请求:**
```json
{
  "message": "请保留免疫应答这个知识点"
}
```

**响应:** ChatResponse
```json
{
  "reply": "已将 1 项决策修改为保留：node_immunity",
  "intent": "keep",
  "updated_decisions": [...],
  "requires_graph_update": true
}
```

### GET /api/chat/history

获取对话历史。

**响应:** ChatHistoryResponse
```json
{
  "messages": [
    {
      "message_id": "abc123",
      "role": "teacher",
      "content": "请保留免疫应答",
      "timestamp": "2026-05-10T10:00:00"
    }
  ]
}
```

## 7. 整合报告

### GET /api/report

获取已生成的报告。

**响应:** ReportResponse
```json
{
  "content": "# 教材知识整合报告\n...",
  "generated_at": ""
}
```

### POST /api/report/generate

生成新的整合报告。

**响应:** ReportResponse

## 8. 数据模型

### Textbook
```typescript
{
  textbook_id: string;
  filename: string;
  title: string;
  file_type: string;
  total_pages: number;
  total_chars: number;
  status: "uploaded" | "parsing" | "parsed" | "failed";
  chapters: Chapter[];
}
```

### KnowledgeNode
```typescript
{
  id: string;
  textbook_id: string;
  name: string;
  aliases: string[];
  definition: string;
  category: string;
  chapter: string;
  page: number;
  source_quote: string;
  frequency: number;
  status: "raw" | "merged" | "kept" | "removed";
}
```

### MergeDecision
```typescript
{
  decision_id: string;
  action: "merge" | "keep" | "remove";
  affected_nodes: string[];
  result_node: string | null;
  reason: string;
  confidence: number;
  status: string;
}
```

# 需求分析

## 1. 项目目标

构建一个学科知识整合智能体，能够：
- 自动解析 7 本医学教材（PDF/MD/TXT）
- 构建跨教材知识图谱
- 通过语义去重将知识点压缩至原始内容的 ≤30%
- 提供带引用的 RAG 问答
- 支持教师通过自然语言反馈修改整合决策
- 生成完整的整合报告

## 2. 知识点粒度定义

### 2.1 粒度标准

知识点的粒度定义为**一个独立的、可被引用的教学概念单元**：

- **最小粒度**: 单一术语的定义（如"细胞膜是由磷脂双分子层组成的"）
- **最大粒度**: 一个完整的知识框架（如"细胞的结构与功能"）
- **推荐粒度**: 一个教学要点（如"线粒体的功能"）

### 2.2 抽取规则

1. 每个章节最多抽取 10 个知识点节点
2. 每个知识点的定义不超过 80 字
3. 必须包含原文引用（source_quote）
4. 知识点之间最多 15 条关系边

## 3. 去重标准

### 3.1 相似度阈值

| 相似度范围 | 处理方式 |
|-----------|---------|
| ≥ 0.90 | 自动合并 |
| 0.82 - 0.90 | LLM 判断 |
| < 0.82 | 保留为独立知识点 |

### 3.2 合并判断原则

1. 同义词、中英文术语、不同表达但定义等价 → 合并
2. 上下位概念 → 不合并
3. 应用场景相同但概念不同 → 不合并
4. 证据不足 → 保守保留

### 3.3 压缩公式

```
compression_ratio = compressed_chars / original_chars × 100%
```

目标：compression_ratio ≤ 30%

## 4. 压缩策略

### 4.1 重要性评分

```
importance = 0.35 × frequency + 0.25 × graph_degree + 0.20 × chapter_weight + 0.20 × citation_support
```

- **frequency**: 知识点在教材中出现的频次
- **graph_degree**: 知识点在图谱中的度数（连接数）
- **chapter_weight**: 章节权重（核心章节 > 补充章节）
- **citation_support**: 被其他知识点引用的次数

### 4.2 压缩优先级

1. 低重要性节点优先删除
2. 重复定义保留最完整版本
3. 前置依赖链上的核心知识点受保护
4. 高频知识点优先保留

## 5. RAG 分片策略

### 5.1 分片参数

| 参数 | 值 | 说明 |
|------|-----|------|
| chunk_size | 600 字符 | 滑动窗口大小 |
| chunk_overlap | 80 字符 | 窗口重叠 |
| top_k | 5 | 检索返回数量 |

### 5.2 分片理由

- 600 字符约等于一个教学段落，保持语义完整性
- 80 字符重叠确保边界信息不丢失
- 滑动窗口比分段更平滑，避免硬切割

### 5.3 检索策略

1. **向量检索**: sentence-transformers 编码，余弦相似度排序
2. **关键词检索**: BM25 算法作为后备
3. **混合排序**: 0.7 × vector_score + 0.3 × bm25_score

## 6. 引用规范

### 6.1 引用格式

```
[教材名称, 章节名, 第X页]
```

### 6.2 引用规则

1. 每个关键结论必须附引用
2. 引用必须来自教材原文
3. 不得使用外部知识补充
4. 上下文不足时回答"当前知识库中未找到相关信息"

## 7. 教师反馈机制

### 7.1 支持的操作

| 操作 | 触发词示例 | 效果 |
|------|-----------|------|
| explain | "为什么合并XXX" | 解释决策原因 |
| keep | "请保留XXX" | 将删除决策改为保留 |
| remove | "删除XXX" | 将保留决策改为删除 |
| split | "请把XXX分开" | 将合并决策拆分 |
| merge | "合并XXX和YYY" | 请求合并 |

### 7.2 目标识别

1. 优先识别引号内的文本（"免疫应答"）
2. 无引号时提取 2-8 字的中文关键词
3. 过滤停用词（"为什么"、"应该"等）

```
┌─────────────────────────────────────────────────────────┐

│  │ - Upload │ (ECharts Force)     │ - Node Detail    │  │

│  │ - Tree   │ - Zoom/Pan/Drag     │ - RAG            │  │

│  └──────────┴─────────────────────┴──────────────────┘  │
└────────────────────────┬────────────────────────────────┘
                         │ HTTP (Axios)
┌────────────────────────┴────────────────────────────────┐
│                   Backend (FastAPI)                       │
│  ┌─────────────────────────────────────────────────────┐ │
│  │                    Routers Layer                     │ │
│  │  /textbooks  /graph  /integration  /rag  /chat  /report│
│  └────────────────────────┬────────────────────────────┘ │
│  ┌────────────────────────┴────────────────────────────┐ │
│  │                   Services Layer                     │ │
│  │  parser → extraction → alignment → rag → chat → report│
│  └────────────────────────┬────────────────────────────┘ │

│  └─────────────────────────────────────────────────────┘ │

```

## 2. 数据流

```
Upload PDF/MD/TXT
       │
       ▼
  Parser Service ──→ Chapter[] (JSON)
       │
       ▼
  Extraction Service ──→ KnowledgeNode[] + KnowledgeEdge[]
       │                    (LLM or Rule-based)
       ▼
  Graph Service ──→ GraphResponse (JSON)
       │
       ▼
  Alignment Service ──→ MergeDecision[] + Merged Graph
       │                  (Embedding + Union-Find)
       ▼
  RAG Service ──→ Indexed Chunks (FAISS)
       │
       ▼
  Chat Service ──→ Modified Decisions
       │
       ▼
  Report Service ──→ Markdown Report
```

## 3. API 设计

### 3.1 教材管理

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /api/textbooks/upload | multipart/form-data (file) | Textbook |
| GET | /api/textbooks | - | Textbook[] |
| GET | /api/textbooks/{id} | - | Textbook |
| POST | /api/textbooks/{id}/parse | - | Textbook |

### 3.2 知识图谱

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /api/graph/build | ?textbook_id=xxx | GraphResponse |
| GET | /api/graph | - | GraphResponse |
| GET | /api/graph/merged | - | GraphResponse |

### 3.3 跨教材整合

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /api/integration/run | - | IntegrationRunResponse |
| GET | /api/integration/decisions | - | MergeDecision[] |
| PATCH | /api/integration/decisions/{id} | ?action=keep/remove/merge | MergeDecision |

### 3.4 RAG 问答

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /api/rag/index | - | {status, books, chunks} |

### 3.5 教师反馈

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| POST | /api/chat | {message} | ChatResponse |

### 3.6 整合报告

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| GET | /api/report | - | ReportResponse |

## 4. 技术栈选型

| 层级 | 技术 | 选择理由 |
|------|------|---------|
| 后端框架 | FastAPI | 异步支持好，自动生成 OpenAPI 文档 |
| 数据校验 | Pydantic | 类型安全，与 FastAPI 深度集成 |
| PDF 解析 | PyMuPDF | 速度快，支持 sort=True 保序 |
| 嵌入模型 | sentence-transformers | 本地运行，无 API 依赖 |
| 向量存储 | FAISS | 高效相似度搜索 |
| 前端框架 | React + Vite | 快速开发，HMR 体验好 |
| 图谱可视化 | ECharts Graph | 力导向图布局，交互丰富 |
| HTTP 客户端 | Axios | 拦截器支持，类型友好 |
| LLM 接口 | OpenAI 兼容 | 支持 DeepSeek/Qwen 等多种模型 |

## 5. 存储设计

```
backend/storage/
├── uploads/       # 原始上传文件
├── parsed/        # 解析后的 JSON
│   └── {textbook_id}.json
├── graphs/        # 知识图谱 JSON
│   └── graph.json
├── vectors/       # 向量索引（预留）
└── reports/       # 生成的报告
    └── report.md
```

## 6. 错误处理策略

| 场景 | 处理方式 |
|------|---------|
| LLM API 不可用 | 自动降级到规则提取 |
| 嵌入模型不可用 | 使用 difflib 字符串相似度 |
| FAISS 不可用 | 使用关键词检索 |
| JSON 解析失败 | LLM 修复 → 规则回退 |
| 文件格式不支持 | 返回 400 错误 |
